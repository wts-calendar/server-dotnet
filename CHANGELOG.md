# Changelog

All notable changes to `Wts.Calendar.AspNetCore` are documented here.

## 1.0.0 - 2026-09-02

- Added visible-range event loading and item lookup endpoints.
- Added create, replace, and delete mutations with strong ETags.
- Added optional `If-Match` enforcement and stale-version conflict responses.
- Added bounded query, payload, identifier, and event validation.
- Added RFC 7807-compatible problem responses.
- Added pluggable storage with an explicitly non-production in-memory store.
- Added a runnable ASP.NET Core example and loopback conformance suite.
