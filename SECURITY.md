# Security policy

## Supported versions

Security fixes are provided for the latest stable `Wts.Calendar.AspNetCore`
release.

## Reporting a vulnerability

Email `suman.mandal@webskitters.com` with the affected package version, impact,
reproduction steps, and any suggested mitigation. Do not open a public issue for
an unpatched vulnerability and do not include production credentials or customer
event data.

The host application remains responsible for authentication, authorization,
tenant isolation, durable persistence, CORS, rate limits, request-size limits,
and production monitoring.
